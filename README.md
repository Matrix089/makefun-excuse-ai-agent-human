A tiny Python program that writes one original excuse an AI agent gives its human for missing a deadline to /output/entry.txt for make.fun's The Excuse an AI Agent Gives Its Human bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
